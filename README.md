# AVESİS SDG Web Scraper 

Bu proje, akademik veri tabanlarından Sürdürülebilir Kalkınma Hedefleri (SDG) ile ilgili verileri otomatik olarak çekmek için geliştirilmiştir.

##  Teknik Özellikler
- **Dil:** Python
- **Kütüphane:** Selenium (Web Otomasyonu)
- **Veri İşleme:** Pandas
- **Tarayıcı:** Chrome (Webdriver)

##  Projenin Amacı
Akademisyenlerin veya kurumların sürdürülebilirlik alanındaki çalışmalarını analiz etmek amacıyla, manuel veri toplama sürecini otomatiğe bağlamak ve veriyi analiz edilebilir formatta (Excel/CSV) sunmak.

##  Nasıl Çalışır?
1. Selenium botu AVESİS portalına giriş yapar.
2. Belirlenen 17 Sürdürülebilir Kalkınma Hedefi altındaki yayınları tarar.
3. Verileri çeker, temizler ve yapılandırılmış bir veri setine dönüştürür.

##  Endüstri Mühendisliği Perspektifi
Bu proje, büyük veri setlerinin toplanması ve süreçlerin dijitalleştirilmesi yoluyla karar destek sistemlerine veri sağlama yetkinliğini göstermektedir.
